## Quer ajudar o projeto?

### 1 - Ajude com tempo

Mande seu Pull Request [aqui](https://github.com/alexrios/gomodules) ou entre em contato comigo.

### 2 - Ajude com uma doação

Como nem todo mundo tem tempo para ajudar, é possível ajudar com doações para o projeto continuar! Considere patrocinar o projeto.
